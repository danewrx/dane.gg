# Shared packages

This directory contains reusable code consumed by the applications.

| Directory | Purpose |
| --- | --- |
| [shared](shared/README.md) | TypeScript utilities used by both frontend and backend |

Keep code here independent of application-specific routes, components, and server startup.
Code used by only one application belongs in that application's source directory.
See [apps](../apps/README.md) for the application layout.
