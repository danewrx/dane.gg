# Documentation screenshots

This directory contains PNG images embedded in the [root README](../../README.md).

- `public-*.png` shows public pages, including the homepage, blog, projects, about, and contact.
- `admin-*.png` shows the login page, dashboard, content lists, editors, and theme configuration.

Use descriptive filenames and a consistent 1440 × 900 viewport when updating the images.
Wait for fonts, content, and animated headings to finish loading before capturing a page.
Keep credentials, session tokens, and private account information out of screenshots.

When adding or removing an image, update its README entry and verify the relative link.
